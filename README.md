# Tokyo
# 🗼 8/31 - 9/4 東京自由行 PWA 旅遊手冊

> 專為五天四夜東京自由行量身打造的 Progressive Web App (PWA) 隨身互動旅遊指南。  
> 採用 **Tokyo DisneySea 25th Sparkling Jubilee（璀璨蒂芬妮藍綠漸層）** 主題設計，支援手機離線快取、全螢幕原生體驗與即時狀態記憶。

---

## 🌟 核心功能特色

### 🗺️ 1. 互動式每日行程導覽 (Itinerary)
* **時間軸卡片**：清楚掌握每日交通班次、乘車月台、景點攻略與退房/報到提醒。
* **精準 Google Maps 導航**：每個景點與店家均附帶專屬「📍 導航」按鈕與快捷店家清單，一鍵直達地圖。
* **機票卡片設計 (Boarding Pass)**：去程 (KHH ➔ NRT) 與回程 (HND ➔ TSA) 機票擬真卡片，航班代碼、航廈時間一目了然。
* **可愛路線地圖 (Leaflet.js + CartoDB Voyager)**：
  * 每日專屬粉嫩繪本風動態地圖。
  * 常駐可愛地標小標籤（點擊標籤亦可直接開啟 Google 地圖）。
  * 自動繪製跨區交通動線（成田/羽田機場、迪士尼、御殿場東名高速、澀谷/自由之丘）。

### 🧳 2. 隨身與託運行李清單 (Luggage Checklist)
* 完整收錄行前必備 12 大類隨身/託運行李項目。
* 支援點擊勾選劃線、一鍵重置。
* 支援自訂新增與刪除物品。
* **LocalStorage 自動記憶**：勾選狀態即使重新整理或關閉瀏覽器也不會遺失。

### 🛍️ 3. 必買購物清單 (Shopping Wishlist)
* 圖文並茂購物願望清單。
* 支援**輸入日幣/台幣價格標籤**（如：`¥3,200`、`NT$ 450`）。
* 支援**手機相簿直接上傳參考圖片**（圖片轉為 LocalStorage 離線儲存）。
* 點擊縮圖可全螢幕放大預覽大圖。

### 📝 4. iOS 備忘錄 & 每日待辦 (Apple Notes Style)
* 深度還原 iPhone 備忘錄經典的**琥珀金圓形 Checkbox** 與便條紙風格。
* 支援天數分類（全部 / Day 1 ~ Day 5 快速切換）。
* **自由速記筆記本**：隨手紀錄置物櫃號碼、密碼或店家筆記，打字即時自動儲存。

## 📱 手機「加入主畫面」安裝教學 (PWA)

本網頁支援 PWA 標準，可直接作為獨立 App 使用（無網址列、支援全螢幕）：

### 🍎 iOS (iPhone / Safari)
1. 使用 **Safari** 瀏覽器開啟專案網頁。
2. 點選底部工具列的 **「分享」按鈕**（中間向上箭頭圖示）。
3. 往下滑動並選擇 **「加入主畫面 (Add to Home Screen)」**。
4. 點選右上角「新增」，手機桌面即會出現專屬 App 圖示。

### 🤖 Android (Chrome)
1. 使用 **Google Chrome** 開啟專案網頁。
2. 點選右上角 **「⋮」選單**。
3. 選擇 **「安裝應用程式」** 或 **「新增至主螢幕」** 即可。
